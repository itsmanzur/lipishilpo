This spellchecking dictionary was created by Jacob Thomas for accurate spellchecking according to Bangla Academy rules broadly and Prothom Alo's practice more specifically. Read more at http://banglatypefoundry.com/spellchecker/

Shipped as gzip (bn-BD.aff.gz, bn-BD.dic.gz) to keep the plugin small.
The editor decompresses them in the browser before Hunspell/nspell loads.
